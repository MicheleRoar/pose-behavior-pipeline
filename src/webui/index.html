Advanced settings

Only used by the YOLO26 Segment backend (Ultralytics' model.track()). SAM 3.1/SAM2 track people on their own (chunked video propagation + id reconciliation, see README) — this choice has no effect for those backends, hence hidden when selected.

SAM 3.1/SAM2 process the video in overlapping windows to bound memory use (see README). "Re-detect every" re-runs YOLO inside the chunk too, not just at its boundary — leave empty to keep one detection per chunk. With a SAM 3.1 text prompt set, avoid combining this with a low "Re-detect every" value — injecting a person mid-chunk can make already-tracked people flicker (SAM 3.1's internal confirmation state is session-wide, see sam31_estimation.py). Prefer a smaller "Chunk length" instead.

Appearance embedding (OSNet)

Adds a deep-learning appearance signal (OSNet) to Identity & Re-identification, on top of the built-in signature/color/position matching — the person's visual "fingerprint" is refined every frame they're visible (like StrongSORT's feature memory), making re-entries after leaving frame more reliable. Only used when Identity mode is "Track + re-identify". Slower per frame; requires the optional 'torch'+'torchreid' packages (see requirements.txt).

'torch'/'torchreid' not detected on this machine — install them (see requirements.txt) to enable appearance embedding.
